このリポジトリは公開されているので、個人情報(本名・勤務先・メールアドレス)は書かない。

## 目標
- オーナーのサイト全体で、まず月1万円の収益。このサイトは成果報酬リンク(A8)で、承認された成果が月2〜3件で届く。
- 見る数字は `affiliate_click` と検索クリック(CLAUDE.md「収益化の進め方」)。ページビューや記事数は目標ではない。

## 方針(詳しくは CLAUDE.md)
- 社名を含まない比較・不安の検索に、このサイトの実測データで答えるページを作る・深める。薄い量産はしない。
- 価格を推測・創作しない。提携の有無で並び順や文言を変えない。提携リンクにはPR表記。
- お金・新規申込み・アカウント作成・パスワード・DNS/Vercel設定は提案にとどめる。

## 作業場の制約(2026-11-15に確認)
- クラウドの作業場からは kin-hikaku.com も各社サイトも接続できない(プロキシで拒否、WebFetchも名前解決不可)。
  公開サイトの表示確認・各社ページでのキャンペーン確認・取得スクリプトの単体実行はできない。
  代わりに、手元で `npm run build` → `npx next start` → Playwright(幅375px)で確認している。
- GitHub への push は main に直接できた(add_repo は「already attached」)。
