# 金・貴金属買取相場比較サイト

主要な金・貴金属買取店の日次買取参考価格を比較し、重さを入力した概算計算や、
重視するポイントに応じたおすすめ店診断ができるサイトです。

## セットアップ

```bash
npm install
npm run dev
```

`http://localhost:3000` で確認できます。

## 主な機能

- `/compare` — 純度・対応地域で絞り込める相場比較表
- `/simulator` — 重さ(g)と純度を入力して各社の概算買取額を計算
- `/finder` — 「大手に任せたい」「とにかく高価買取」「安心した買取ができる店」など
  重視するポイントを選ぶとおすすめ順に会社を表示する診断

## データの更新

価格データは `data/companies.json` に保持しています。手動で編集してもよいですし、
一部の会社はスクレイパーで自動更新できます。

```bash
# 全社まとめて実行
npm run scrape

# 1社だけ実行(会社IDはdata/companies.jsonのid参照)
node scripts/scrape/index.mjs otakaraya
```

### スクレイパーの実装状況

`scripts/scrape/sources/` 配下に会社ごとの実装があります。

- **実装済み(16社)**: おたからや・コメ兵・なんぼや(JSON、要鮮度確認)・ジュエルカフェ・
  買取エリート・キングラム・ベストライフ・ブラリバ・シグマ・ギャラリーレア・まねきや・
  高山質店(K18のみ)・ゴールドミセス・ネクサス・銀座屋(単一レートのみ)・大蔵屋
- **未実装(2社)**: 買取大吉・大黒屋 — 両社とも価格がJavaScriptで書き換えられる方式で、
  curlでの静的取得では信頼できない値(食い違い・未更新の0円など)しか拾えなかったため、
  実際にJSが呼んでいるAPIエンドポイントの特定が必要(詳細は各ファイルのコメント参照)。

なお、おたからや・まねきや・買取大吉(の一部フォールバック値)で全く同じ数値が
確認されており、業界で共通の相場データ(仕入れ元)を参照している買取店が複数存在する
ようです。

### スクレイピング時の注意

- User-Agentは `scripts/scrape/lib/fetchHtml.mjs` の `SCRAPER_USER_AGENT` 環境変数で
  上書きできます。既定値はダミーなので、実運用前に実在の連絡先を含むUser-Agentに
  差し替えてください。
- なんぼや・ジュエルカフェ・買取エリートなど一部サイトはrobots.txtでClaudeBotや
  GPTBot等のAIクローラーを名指しでブロックしています。本ツールはそれらの名称を
  騙らず自社名義のUser-Agentを使う設計ですが、商用展開する前に各社に利用目的を
  問い合わせることを推奨します。
- エコリング(eco-ring.com)は強いボット対策(robots.txt自体が403)のため、
  自動取得の対象から除外しています。
